# RSP

My self-paced run through Ravi's Study Program: CTCI, The Algorithm Design Manual, and Python practice.

## Layout

```
notes/
  ctci/            Cracking the Coding Interview, numbered in reading order
  adm/             The Algorithm Design Manual, by chapter
  python/          Python reference notes (DSA toolkit, OOP)
  failures.md      problems to redo cold (add when needed)
  weekly.md        weekly updates (add when needed)
practice/
  oop/             OOP exercises
implementations/   data structures and algorithms built from scratch
```

## Naming

- Lowercase with hyphens for notes: `03-big-o.md`
- Lowercase with underscores for Python: `bank_account.py`
- New CTCI notes get the next number. New ADM notes are `chN-...md`
